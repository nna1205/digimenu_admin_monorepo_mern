## Multi-Store E-commerce Platform MERN Stack

A modern, responsive e-commerce platform that allows restaurant owners to manage their information, categories, products with customised options, and orders with real-time status updates.

## About this repository

For the purpose of showcasing, this repository contains both the code for the frontend and backend, combined from two separated repositories. It is built using the MERN stack, with a focus on performance, scalability, and maintainability.

## ✨ Features

- Store management for owners
- Product and inventory management
- Order processing and tracking
- Sales analytics and reporting

## 🛠 Tech Stack

- **Frontend Framework**: [React.js](https://react.dev/)
- **Component Library**: [shadcn/ui](https://ui.shadcn.com/)
- **Frontend State Management**: [Redux Toolkits](https://github.com/pmndrs/zustand)
- **Form Handling**: [React Hook Form](https://react-hook-form.com/) with [Zod](https://github.com/colinhacks/zod) validation
- **Database Provider**: [Supabase](https://supabase.com/) with [Tanstack Query](https://tanstack.com/query)
- **Database ORM**: [Prisma](https://prisma.io/)
- **Cache Management**: [Redis](https://redis.io/)
- **Authentication**: [Clerk](https://clerk.com/)
